# Publication and acceptance

## Git history

The old private Git graph is deliberately not imported. Its accepted 2.1.287 source was already an integration of official restorations and local customizations. The public initial `C` import therefore represents a **sanitized mixed baseline**, not a claim that every imported line is local-only or a pristine official `P` snapshot. Later `P` commits isolate official client/runtime corrections, and later `C` commits isolate distribution and local improvements. All public author/committer identities are administrator <admin@example.com>. Future work should continue P/C classification by change block.

## Export

Only the exact reviewed source/configuration/native-resource/build-tool/test selection is published. Historical operational reports, original Git identities, credentials, real sessions, dependency caches and host-specific evidence are omitted. Executable syntax, prompt strings and native resources keep their accepted behavior/bytes. Seven source files have exact nonfunctional comment-only developer-home redactions, verified by identical TypeScript AST printing without comments. Two documentary proof/provenance JSON files have one home fixture/example redacted each; their original evidence digests remain historical references, not hashes of the redacted text. Re-obtain raw upstream input before using such proof snippets for regeneration. JSON provenance personal paths become repo-relative references where an identical upstream copy is included; otherwise `provenance-reference://not-bundled/` explicitly denotes an omitted historical input, with hashes/ranges retained. Such URIs are not executable filesystem paths. Re-obtain official npm inputs independently before running recovery tools.

`CLAUDE_OFFICIAL_MODULES_DIR` supplies the fixed 2.1.287 darwin-arm64 extraction root to `scripts/official/tls-dispatch-287.mjs --check`. Its exact manifest/module/declaration hash checks remain enabled. Other portable extraction, indexing, registration and version-diff tools accept their documented explicit inputs; old machine-specific generator fixtures are not bundled.

## Accepted local scope

The original full source TypeScript configuration passed with an 8 GiB Node heap before export; export-only metadata/documentation cleanup does not establish fresh six-platform acceptance. A real macOS arm64 installation archive was created, extracted and installed offline with its own public Bun 1.4.3 executable; the public launcher returned the fixed version. GitHub jobs must validate the final published checkout independently.

Original/source tests use synthetic local OAuth records and fixed TLS/SSE, not real login or model requests. Measured ClientHello/settings/header/session dispatch scopes and actual in-flight RST_STREAM CANCEL evidence are finite. Response DATA chunk counts and stream-credit increments differ under public Bun consumption/scheduling; this is not full wire-byte parity. Public Bun is intentionally not the embedded official executable.

## Six-platform release

`release.yml` runs six native test/build/extract/offline-install jobs plus the original full type check. On `v2.1.287`, release creation requires all jobs, the tested tag commit and all six archive checksums/receipts. Packages contain source, native Bun and target production dependencies, not a single-file compiled executable. Destination installation does not resolve dependencies over the network. Real OAuth/account qualification and graphical desktop/Chrome actions are not CI claims.

## Preserved local differences

Existing system-prompt additions/trimming, refusal/fallback handling, thinking summary preference, third-party compatibility, full visible history, transcript detail, telemetry choices, shared Web execution and workspace boundaries are preserved. These are local C differences, not official 1:1 claims. Service-side host injections and account-qualified paths are not fabricated. AWS/Vertex-only upstreams and previously excluded unsupported complex entry points remain outside the accepted scope.
